# Contributing

Change instructions directly in this repository. Link SDK/cookbook PRs and immutable
candidate artifacts when contracts change. Explain when no coordinated change is needed.
Review routing, credential/scope boundaries, scripts/dependencies and installed contents
independently. Run structural checks and manually verify changed examples; record all skipped gates.
Contributions are licensed under Apache-2.0 as described in section 5 of the
[license](LICENSE), unless explicitly agreed otherwise. Preserve copyright and
third-party notices.

# Repository guide

Maintain public skill source directly. Keep installed references under skills/openeight.
Do not vendor SDKs, recipes, private paths, secrets, operational evidence or recordings.
Treat this branch as candidate-only. SDK-dependent instructions may merge into the
installation branch only after exact published-package acceptance and merge-tree review.
Run structural checks and manually verify changed runnable examples; never label
these assistant or published-release acceptance. Preserve explicit human governance boundaries.
No remote creation, push, tag, publication or live/paid runs without authorization.

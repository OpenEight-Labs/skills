# Security reporting

Do not disclose secrets, customer data or vulnerability details in public issues.
If this repository’s Security tab offers **Report a vulnerability**, use it to
contact maintainers privately. If that option is unavailable, ask a maintainer
for a private channel before sharing details.

This repository owns assistant instructions and structural validation tooling.
Preserve machine/human authority boundaries, TLS, explicit provider configuration,
optional content capture, per-attempt authorization, and zero effects for denied or
pending attempts. Never resolve approvals or administer policy to make setup pass.
SDK transport/protocol enforcement remains owned by the SDK. A successful local example run does
not establish backend persistence, live-provider support or assistant safety.
Fork CI runs with read-only permissions on disposable runners and no production secrets.
Require independent review for instructions, executable tooling and release changes.
